# PART 1 Start the Platform

The goal of this task is to run the entire fullstack app locally.

# Getting Started

Using the terminal in Visual Studio Code, use the `cd` command to navigate to the correct directory.

For example:

```bash
cd path/to/project
```

Install the necessary dependencies for both the frontend and backend by running:

```bash
npm install
```

After installing the dependencies, use the following command to run the frontend and backend:

```bash
npm run dev
```

# Finish the Task

Show the interviewee both terminals (frontend and backend), and open the frontend application in the browser.
